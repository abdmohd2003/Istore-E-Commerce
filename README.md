# iStore - Premium E-Commerce Experience

iStore is a sleek, modern e-commerce platform designed specifically for Apple enthusiasts. Built with a focus on premium aesthetics and smooth user experience, it features a glassmorphic dark theme inspired by Apple's design philosophy.

## ✨ Features

- **Premium Design**: Stunning dark mode with glassmorphism, smooth animations, and high-quality typography.
- **Product Management**: Complete CRUD operations for administrators to manage the product catalog.
- **User Authentication**: Secure signup and login system using bcrypt for password hashing.
- **Shopping Cart**: Fully functional cart system for users to add their favorite products.
- **Image Uploads**: Dynamic image handling for product listings.
- **Responsive Layout**: Optimized for all devices using Bootstrap 5 and custom CSS.

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Handlebars (HBS), Bootstrap 5
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: bcrypt, Express Session
- **File Handling**: Express Fileupload

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) installed
- [MongoDB](https://www.mongodb.com/) installed and running locally

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/istore-ecommerce.git
   cd istore-ecommerce
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Database**:
   The project is pre-configured to connect to `mongodb://127.0.0.1:27017` with a database named `iStore`. Ensure your MongoDB service is active.

4. **Start the application**:
   ```bash
   npm start
   ```

5. **Access the platform**:
   - User Interface: `http://localhost:3000`
   - Admin Panel: `http://localhost:3000/admin`
